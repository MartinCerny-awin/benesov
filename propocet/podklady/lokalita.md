## Shrnutí pro model

**Přirážka/srážka k ceně bytů za lokalitu** (základ = průměr srovnatelných bytů v Benešově, stejný stav; stav domu se počítá zvlášť). **ODHAD** – žádný hedonický zdroj nebyl dostupný; složky jsou odborný odhad podle vzdáleností a rizik výše.

| Složka | Pesimistická | Realistická | Optimistická |
|---|---|---|---|
| Nádraží 6 min pěšky (R17 40 min, S9 30 min interval) | +2 % | +4 % | +5 % |
| Školy/centrum do 15 min | −1 % | 0 % | +1 % |
| Provoz a hluk II/110 přímo před domem | −3 % | −2 % | −1 % |
| Soused areál/technický provoz, kontejnery, nádražní okraj | −5 % | −3 % | −1 % |
| Nákupy (velké obchody nepěšky) | −1 % | −1 % | 0 % |
| Výhled (Trigema, I/3 – nejasný, kasárny) | 0 % | 0 % | +1 % |
| **Celkem za lokalitu** | **−8 %** | **−2 %** | **+5 %** |

Doporučení: počítat **−2 %** (rozpětí −8 až +5 %). Tržní riziko přiblížit k pesimistickému, pokud jsou provozní/hlukové vlivy areálu nad očekávání.

Další vstupy pro model:
- Záplavové území: **ne** (0 %).
- Hluk: železnice < 50 dB (modelově), silnice II/110 ODHAD 55–65 dB.
- Doba do Prahy: 40 min (R17, hodinově) / 52–55 min (S9, po 30 min). Doba pěšky k nádraží 6 min.
- Technické: **bez plynu**, kotel ve stavbě – ověřit palivo a cenu přechodu na tepelné čerpadlo/plyn (viz otázky).
- Poptávka: kladné saldo migrace (+477 v roce 2022), ale konkurenční nová výstavba 2027+ (Trigema) a výrazná cenová hladina novostaveb (140–170 tis. Kč/m², ODHAD Newstream) – starší byty obvykle výrazně pod tímto.
